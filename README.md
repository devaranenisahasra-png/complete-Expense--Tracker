
# Expense Tracker Website

A responsive personal finance tracker built using HTML, CSS, and JavaScript.

## Features

- View total balance, income, and expenses
- Add income and expense transactions
- Delete individual transactions
- Filter income and expenses
- Save data using browser localStorage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a browser.
4. Add income and expense entries to test the project.

## Learning Outcomes

- Learned HTML page structure and CSS styling.
- Practised JavaScript functions and event listeners.
- Learned DOM manipulation and form validation.
- Used arrays to store and filter transactions.
- Learned how browser localStorage saves data.
